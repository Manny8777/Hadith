# Al-Jami brand assets

`al-jami-logo.png` and `library-atmosphere.png` are the unmodified artwork supplied in the user's Hadith theme handoff. The logo's transparent canvas is framed with CSS in `BrandMark`; no generated replacement is used. The small SVG favicon simplifies the arch, eight-point star, and open-book emblem for browser tabs.

The atmosphere image is decorative and limited to the homepage hero. Reading surfaces remain plain. See `app/globals.css` for the parchment, ivory, emerald, antique-gold, and dark-mode theme tokens.
